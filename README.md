# Factorial Program - Week 2

## Description
Python program to find the factorial of a given number.

## File: factorial.py
- Takes integer input from user
- Calculates factorial using a loop
- Prints result in format `Factorial of 5 = 120`

## How to Run
```bash
python factorial.py
```

## Example
Input:
```
Enter a number: 5
```
Output:
```
Factorial of 5 = 120
```
