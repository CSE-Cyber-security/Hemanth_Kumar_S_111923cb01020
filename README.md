
# Password Strength Checker

## Description
A Python program that evaluates password strength
using five basic security criteria.

## Criteria
- At least 8 characters
- At least one uppercase letter
- At least one lowercase letter
- At least one digit
- At least one special character

## Strength Levels
- Strong: 5 conditions satisfied
- Moderate: 3 or 4 conditions satisfied
- Weak: 0, 1 or 2 conditions satisfied

## How to Run
python password_checker.py

## Technologies
Python 3
